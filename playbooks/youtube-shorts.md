# 유튜브 숏츠 운영 기준

버전: 1.1 · 결정일: 2026-09-05 · 상위 규칙: [OLYMPUS v1.1](../OLYMPUS_Agent_Architecture_v1.1.md)

이 문서는 이슈 [#1](https://github.com/BoxLogoDev/olympus_grokbot/issues/1)과 [#2](https://github.com/BoxLogoDev/olympus_grokbot/issues/2)에서 채택한 운영 기준이다. 알고리즘의 보편 법칙을 선언하거나 실제 공개 일정·봇·루틴을 활성화하는 문서가 아니다. 채널별 규칙은 지정된 프로젝트에만 적용한다.

## 1. 근거와 조회 부진 진단 (`OLY-YT-001`)

아르테미스는 외부 주장을 `HYPOTHESIS`, 원문 미확인을 `UNVERIFIED`로 기록한다. SNS 수익·조회 인증을 검증된 인과관계나 운영 목표로 사용하지 않는다. 최신 공식 정책, 허용된 자사 자료, 통제된 실험으로 주장 유형·날짜·적용 범위를 확인한다. 공식 규칙 준수와 콘텐츠 성과 가설은 별도로 판정한다.

조회가 부진할 때 먼저 다음을 본다. 이미 허용된 자료로 확인할 수 없는 항목은 미확인으로 남기며, 이 규칙을 근거로 새 대시보드나 수집 권한을 만들지 않는다.

1. 첫 장면·훅에서 무엇을 전달하며 어디에서 넘기는가?
2. 대본·장면 연결·편집에서 이해가 끊기거나 이탈하는 구간이 있는가?
3. 음성·자막·소리·시각 표현에 시청자의 거부감이나 이해 방해 요인이 있는가?
4. 제목·썸네일이 약속한 내용과 실제 영상이 일치하는가?

좌우반전, RGB 변경, VPN·IP 분리, 특정 길이·새벽 공개, 기계적 댓글·좋아요 유도, 민감 단어 우회 같은 검증되지 않은 방법을 첫 진단이나 자동 처방으로 사용하지 않는다. 민감한 문학 대사는 문맥과 실제 적용 정책으로 검토하며 단어 치환 규칙으로 우회하지 않는다.

TTS 또는 AI 사용 자체를 자동 알고리즘 감점으로 단정하지 않는다. 실제 결과의 전달력·독자적 기여·원본성·시청 경험을 검수한다. 이는 모든 AI 콘텐츠가 정책상 허용된다는 주장이 아니다. 공개 시점에 필요한 정책·권리·합성 콘텐츠 고지 검토를 별도로 통과해야 한다.

## 2. 공개 품질과 제작 기본기

소재 전문성과 영상 제작 품질은 각각 검수한다. 주제에 대한 지식만으로 영상 품질을 통과시키지 않는다. 아래 항목은 OLYMPUS의 내부 품질 기준이며 특정 SNS 아티클을 확인한 결과로 가장하지 않는다.

| 항목 | 확인할 결과 | 제작·수정 담당 | 최종 검수 |
|---|---|---|---|
| 훅 | 초반에 상황·관심 이유가 전달되고 과장하지 않음 | 아프로디테·아폴론의 별도 업무 | 헤라 |
| 이야기·장면 | 대본의 의미와 화면 연결, 장면 순서가 이해됨 | 아폴론·헤파이스토스의 별도 업무 | 헤라 |
| 음성·자막 | 발음·가독성·동기·음량이 이해를 방해하지 않음 | 헤파이스토스 | 헤라 |
| 편집 | 불필요한 공백·중복·깨진 화면·끊긴 소리를 점검함 | 헤파이스토스 | 헤라 |
| 메타데이터 | 제목·설명·썸네일이 최종 영상과 일치함 | 아프로디테·헤르메스의 별도 업무 | 헤라 |
| 독자적 기여 | 기획·서사·해석·편집의 기여와 입력 계보가 설명됨 | 각 제작 부서 | 헤라 |

부서 간 전달은 헤스티아를 경유한다. 표의 복수 부서 표시는 공동 책임 원자 업무를 뜻하지 않는다. 항목별 완료 조건은 프로젝트 시작 시 확정하고 검수 결과를 남긴다. 기준을 충족하지 못하면 원인에 맞는 수정 업무를 만들며, 검수하지 않은 생성 완성본은 공개하지 않는다.

자기 관심 세계·경험·작품을 소개하는 콘텐츠도 전략 후보로 검토할 수 있다. 게임 소개는 예시일 뿐이다. 기존 문학·채널 방향을 바꾸는 지시가 아니며, 아테나가 적합성을 제안하고 제우스가 전략 변경을 결정한다. 단일 SNS 사례로 조회수 우위를 보장하지 않는다.

## 3. 문학 숏츠·Fatal Giggle의 지식과 목표 (`OLY-YT-002`)

적용 대상: 이슈 #1에서 지정한 민음사 월드문학전집 숏츠 및 Fatal Giggle. 다른 프로젝트의 수익 목표를 새로 정하는 조항이 아니다.

- YPP 요건은 메타 참고 지식이다. 배정 완료조건, 공개 슬롯 목표, 소재 선정 기준으로 사용하지 않는다.
- 명목조회수를 2로 나누어 유효조회수라고 단정하지 않는다. 플랫폼이 정의한 지표와 산정 기간을 구분한다.
- 단일 외부 사례의 조회수·달러·RPM을 KPI로 채택하지 않는다. 국가 통계 대시보드를 신설하거나 우회 KPI로 사용하지 않는다.
- 2026-09-05 확인한 공식 안내의 대표 자격 경로는 구독자 1,000명과 최근 12개월의 자격 충족 공개 시청시간 4,000시간, 또는 구독자 1,000명과 최근 90일의 자격 충족 Shorts 조회수 1,000만 회다. 수치 충족 외에 정책·계정·심사 요건이 있으며, 최신 조건은 사용 시 공식 문서에서 다시 확인한다. 이 수치는 헌법의 영구 상수나 운영 목표가 아니다. [공식 안내](https://support.google.com/youtube/answer/72851)

## 4. 같은 권의 재시도 (`OLY-YT-003`)

한 배정은 이슈 #1의 기존 3권 단위를 유지한다. 첫 클립·조립 실패를 해당 권 폐기나 전체 파이프라인 중단으로 간주하지 않는다.

1. 실패 업무는 실행·입력·산출물·원인을 부모 신에게 보고하고 헤스티아로 전달한다.
2. 같은 권의 재시도는 헤스티아가 연 **재카드**로만 진행한다. 부서가 독자적으로 같은 권의 실행 카드를 반복 생성하지 않는다.
3. 새 카드에는 `retry_of_task_id`, 대상 권 식별자, 원인, 변경 입력·방법, 승인된 예산, 누적 실패 이력을 연결한다. 기본 실패·비용 상한을 카드 교체로 초기화하지 않는다.
4. 훅 실패 원인이 대본인 경우에만 대본 재카드를 헤스티아 경유로 연다. 영상 조립·도구 오류를 대본 문제로 추정해 재작성하지 않는다.
5. 공장형 다회 시도·물량 확대를 복구 방법으로 사용하지 않는다. 동일 실패 두 번 이후에는 자동 반복을 멈추고 원인·변경점에 근거한 헤스티아 판단을 기록한다.

재카드 발행은 미래 외부 게시 승인이나 새 인간 생성의 포괄 허가가 아니다. 기존 인간을 먼저 재사용하고 인간·과거 작업 기록은 삭제하지 않는다. 이 조항은 해당 채널의 같은 권 재시도에 대해 일반 재시도보다 엄격하게 적용된다.

## 5. 보존할 채널 결정 (`OLY-YT-004`)

아래는 이슈 #1의 최신 명시적 결정이다. 외부 조언이나 이번 이슈 채택으로 변경하지 않는다.

- 오리지널 문학 숏츠의 방향과 기존 제작·편집 파이프라인을 유지한다. CapCut으로 교체하지 않는다.
- 기존 공개 슬롯 `07·12·18·19`를 유지한다. 현재 설정의 시간대·요일·채널 연결을 보존하며 이 문서에서 추정하거나 스케줄을 새로 만들지 않는다.
- 양산 공장형 전략, 해외 짜깁기 다채널 잭팟, 쇼핑파트너스·쿠팡·채널 구매·조회수 판매로 전환하지 않는다.
- 다른 채널의 자사몰·제품 노출·멤버십·롱폼 AI 플레이리스트를 이 프로젝트에 이식하지 않는다.
- 인도·필리핀 등 특정 국가 노출 변화를 이유로 채널을 폐기하지 않는다. 국가 통계 대시보드도 신설하지 않는다.
- RPM을 이유로 숏츠 길이를 바꾸거나 트래픽 소재로 권 선정 기준을 변경하지 않는다.
- 출처 계정에 게시·좋아요·질문 댓글을 남기지 않는다.

이 결정은 채널 운영 범위의 제약이다. 다른 프로젝트에 동일한 수익·도구 금지를 자동 확장하지 않으며, 기존 결정의 변경은 별도 제우스 판단과 문서 반영을 거친다.

## 6. 예약·게시의 승인

반복 스케줄은 `OLY-RTN-001`의 최종 버전 수동 검증 2회, 중단·검토 조건, 제우스 활성화 승인을 충족해야 한다. 예정된 승인 대기는 정상 단계이고, 예정 밖 수동 오류 수습은 자동화 미준비 신호다.

게시마다 영상·썸네일 등 모든 파일 버전·해시와 제목·설명·태그·공개 범위·예약 시각·시간대·플랫폼 설정을 포함한 실행 매니페스트를 승인받는다. 스케줄 등록 승인은 미래 게시물 승인으로 대체할 수 없다. 응답 유실로 게시 여부가 불명확하면 원격 기록 대조 전 다시 게시하지 않는다.

## 7. 출처 확인 범위와 보류

- [YouTube 추천 시스템 설명](https://blog.youtube/inside-youtube/on-youtubes-recommendation-system/): 2021년 공식 설명에서 여러 신호를 조합한다고 확인했다. 이를 현재의 고정 공식이나 성과 보장으로 사용하지 않는다.
- [YPP 공식 안내](https://support.google.com/youtube/answer/72851): 2026-09-05 확인. 수치·산정 기간은 참고 지식이며 적용 때 최신 내용을 재확인한다.
- 이슈 #2의 수동 검증·팀원 템플릿 제안은 이슈에 적힌 내용을 자체 운영 기준으로 평가해 수정 채택했다. 연결된 X 원문은 이번 조회에서 가져오지 못했으므로 원문의 사실 검증 완료로 표시하지 않는다.
- 이슈 #2의 [영상제작 기본기 아티클](https://x.com/mung99933/status/2095742698028511326)과 [보조 링크](https://x.com/mung99933/status/2095745938795168100)는 원문 미확인으로 보류한다. 본문을 확보하면 구체 주장·근거·충돌을 확인한 후 별도 제안으로 재검한다. 이 문서의 내부 품질 기준을 그 아티클에서 추출했다고 주장하지 않는다.
