# 민음사 문학 YouTube Shorts

현재 운영 기준: **2026-09-24 채택 · [이슈 #19](https://github.com/BoxLogoDev/olympus_grokbot/issues/19)**

민음사 세계문학전집 YouTube Shorts를 배정하고, 제작하고, 게이트를 통과한 뒤 공개한다. 운영 전문은 [SHORTS_Operating_v1.md](SHORTS_Operating_v1.md), 회차 절차는 [유튜브 숏츠 플레이북](playbooks/youtube-shorts.md)을 따른다. 채택 기록은 [2026-09-24 결정](docs/decisions/2026-09-24-shorts-only-ops.md)에 있다.

## 역할

창구는 **[숏츠] 총괄** 하나다. 총괄은 접수를 받고, 한 직무를 한 슬롯에만 나누고, 핸드오프 4줄(역할·산출·성공·금지)을 넘기고, Facts / 진행 / 막힘 / 승인요청으로 보고한다.

| 표시명 | 직무 |
|---|---|
| [숏츠] 총괄 | 접수, 한 직무를 한 슬롯에 배분, 핸드오프, 보고 |
| [숏츠] 배정 | 회차 확정 |
| [숏츠] 리서치 | 작품 조사만 |
| [숏츠] 대본 | 45–60초 대본 |
| [숏츠] 영상생성 | Imagine 컷 |
| [숏츠] 편집조립 | 최종 조립 |
| [숏츠] 훅·썸네일 | 훅·썸네일 |
| [숏츠] 품질게이트 | PASS / CONDITIONAL / FAIL |
| [숏츠] 채널기준 | 채널 적합성 피드백 |
| [숏츠] 발행게이트 | 발행 준비 확인 |
| [숏츠] 메타·공개 | 메타데이터와 업로드·공개만 |
| [숏츠] 채널운영 | 슬롯·큐·홀드 상태 (있을 때) |

## 파이프라인

배정 → 리서치 → 대본 → 영상생성 → 편집조립 → (훅·썸네일 병행) → 품질게이트 → 발행게이트 → 메타·공개

## 규칙

- 공개 슬롯은 **07·12·15·18·19·21 KST**다. 큐 선두는 건너뛰지 않는다.
- 자동 큐는 품질게이트 **PASS**만 받는다. CONDITIONAL과 FAIL은 홀드한다.
- 업로드·공개는 **[숏츠] 메타·공개**만 한다.
- **UPLOAD-HOLD**이거나 Studio 한도면 업로드하지 않는다. 재개 지시 뒤에만 업로드한다.
- 운영 문서, 핸드오프, 보고, 영상 대사는 한국어만 쓴다.
- 화면 금기는 폭력, 혈흔, 손 이상, Fatal Giggle 무단 사용이다. 컷 라벨이 화면에 남으면 통과시키지 않는다.

## 먼저 할 일

1. UPLOAD-HOLD를 해제한 뒤 #100부터 순서대로 공개한다.
2. 컷 라벨·혈흔 게이트 실패가 반복되지 않도록 체크리스트를 적용한다.
3. PASS 대기 버퍼를 유지한다. 목표 편수는 총괄 승인요청으로 정한다.
4. 주간 Studio 조회·이탈을 훅·대본 개선에 반영한다.

## 이전 문서

`OLYMPUS_*.md`는 2026-09-24에 종료된 기록이다. 파일은 삭제하지 않는다. 각 파일 첫머리의 폐기 배너가 현재 문서를 가리킨다. 이 저장소 개정은 YouTube 업로드, 예약, Studio 설정을 바꾸지 않는다.
