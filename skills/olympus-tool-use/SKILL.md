# OLYMPUS 도구 사용

상태 DRAFT. 헌법 v1.3 OLY-OPS-001..006과 [도구 운영 절차](../../playbooks/tool-coordination.md)를 따른다.
기존 사용자 권한·예산·시도 상한을 유지한다. 자동 동기화가 설치돼 있다고 가정하지 않는다.

1. 필요한 정보의 기준 원본과 이번 도구 호출 목적을 정한다.
2. 저장된 project_id/task_id와 외부 object_id/URL을 사용한다. 모를 때만 프로젝트·날짜 범위에서 검색한다.
3. 원문과 버전을 확인한다. 검색 발췌·작성 완료 메시지는 판정 증거가 아니다.
4. 사용 가능한 연결/API/CLI를 우선하고 작업에 필요한 필드만 읽거나 갱신한다.
5. 쓰기 응답의 object_id로 다시 읽어 실제 내용·버전·링크를 확인한 뒤 기록 완료로 표시한다.
6. 결과 불명은 대조 후 재개한다. 다른 도구에서 새 객체를 만들어 같은 작업을 중복 실행하지 않는다.
7. GitHub 정책/코드, Notion 목표/결정, 원장 실행 상태, 비공개 원본 자산의 책임을 구분한다.
8. Craft 메모는 채택된 부분을 프로젝트나 이슈에 연결한다. 모든 도구에 같은 본문을 복제하지 않는다.
9. 인계는 수신자가 읽을 수 있는 실제 자료와 확인 결과가 있어야 완료다. 원격 경로·빈 JSON·집계 요약만으로 완료 처리하지 않는다.
10. 실패·오래된 상태·다음 행동을 헤스티아에게 보고한다. 일반 내부 인계는 기존 권한 범위에서 처리한다.

완료 보고에는 무엇을 어디에 기록했는지, 실제로 다시 읽어 확인했는지, 다음 작업의 원본 참조를 포함한다.
정책·승인·문서의 작성자 ID 문자열을 인증된 실행 승인으로 승격하지 않는다.
