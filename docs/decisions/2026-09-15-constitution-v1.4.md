## 슬롯과 정책 전환

1. 기존 89개 슬롯을 보존한다. 헤파이스토스 그림·동작 슬롯 두 개는 SUPERSEDED/신규 배정 금지로 기록하고 아프로디테에 같은 단일 직무의 대체 슬롯 두 개를 추가한다. 총 91개, 배정 후보 89개다.
2. 인간 레지스트리는 변경하지 않는다. 기존 이름·ID·소속·과거 작업을 자동으로 바꾸지 않는다. 실제 전환에서는 새 담당 직무에 맞는 기존 인간을 먼저 확인하고 없을 때만 생성 프로토콜을 따른다.
3. v1.3 헌법·프롬프트는 원문 그대로 보존한다. 현행 플레이북·YAML·템플릿은 v1.4로 연결한다. 과거 정책 커밋이 고정된 시뮬레이션 예시의 버전·해시는 바꾸지 않는다.
4. 실행 환경에서 v1.4와 실제 반영 커밋을 로드하고 기존 카드·인간·도구 연결을 비교한다. 열린 작업은 영향과 전환 시점을 기록한다. 이미 시작한 외부 실행은 결과 대조·비용 정산 후 전환한다.
5. 사용 중인 옛 그림 슬롯·철회 AI 금지·6컷 기본값·19시 FG 연결·PASS 자동 공개 해석을 점검한다. 문서상 규칙 변경과 실제 구성 변경은 따로 기록한다.
6. 단건·묶음 승인, 변경·만료·철회·중복·응답 유실, CONDITIONAL_PASS 홀드, 그림 배분 거부와 상품 분리를 실행 환경에서 검증한다. 증거 전에는 RUNTIME_VERIFIED로 올리지 않는다.
